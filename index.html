Ferramentas

Cursor

Editor com agentes. Os planos agora são um 'pool' de uso partilhado entre o Cursor e o Grok, que renova semanalmente.

Editor/IDE + agentes

Claude Code (planos Claude)

O Claude Code vem incluído em todos os planos pagos do Claude e partilha o mesmo limite de uso que o chat.

Agente de terminal/IDE

OpenAI Codex (planos ChatGPT)

O Codex está incluído nos planos ChatGPT Free, Go, Plus, Pro, Business e Enterprise. Mensagens locais e na nuvem partilham o mesmo limite.

Agente (app, CLI, nuvem)

GitHub Copilot

Funciona com 'GitHub AI Credits' (1 crédito = US$0,01). Completamentos de código são ilimitados nos planos pagos; chat, agente, revisão e CLI gastam créditos.

Extensão IDE + agente + CLI

Gemini Code Assist

Agora focado em equipas e empresas. Licenças por utilizador incluem o Gemini CLI.

Extensão IDE + Gemini CLI (empresas)

Google Antigravity (inclui Antigravity CLI)

Sucessor gratuito do Gemini CLI/Code Assist para indivíduos. A quota paga vem com os planos Google AI.

IDE com agentes + CLI

Windsurf

Desde 19/03/2026 já não há créditos: cada plano tem uma quota que renova diariamente e semanalmente. A página de preços redireciona para devin.ai/pricing.

Editor/IDE + agentes

TRAE

Os planos pagos incluem um valor em dólares de uso de modelos por mês.

Editor/IDE + agentes

Kiro

Funciona com créditos mensais. Os planos pagos aceitam morada de faturação em Angola, Brasil, Moçambique, Cabo Verde e Portugal.

IDE + CLI + Web

Amazon Q Developer

Assistente da AWS para IDE e CLI, com agente de transformação de código Java/.NET.

Extensão IDE + CLI

OpenCode Go

Subscrição barata de modelos abertos (Kimi, DeepSeek, GLM, Qwen…) para usar no OpenCode ou noutro agente.

Subscrição de modelos para agentes

Zed

Editor rápido e open source. Grátis para sempre se usar as suas próprias chaves de API ou agentes externos (Claude Agent, Codex CLI).
